# Dredge documentation

If you are new to Dredge, start with installation, then configure registry
authentication if your registry requires it. Use the command reference when
you know which operation you want to run; use the guides to configure settings,
select an image platform, and interpret command results.

## Command reference

- [`image`](commands/images.md) — Inspect, compare, and export container images
- [`manifest`](commands/manifests.md) — Query, resolve, and delete manifests
- [`referrer`](commands/referrers.md) — List, check, and inspect referrers and retrieve artifact payloads
- [`repo`](commands/repositories.md) — List repositories in a registry
- [`tag`](commands/tags.md) — List or delete tags in a repository
- [`settings`](commands/settings.md) — Manage Dredge configuration
